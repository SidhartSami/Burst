# Burst Download Manager — Privacy Policy

Last updated: October 5, 2026

Burst Download Manager is a Chrome extension that integrates the Chrome browser with the locally installed Burst desktop application.

## Data Handling

The extension does not collect, sell, or use personal information for advertising or profiling.

When the extension intercepts a supported browser download or a user-selected magnet link, the relevant URL is sent to the locally installed Burst desktop application through Chrome Native Messaging.

The extension does not transmit these URLs to a remote analytics, advertising, or tracking service.

## Local Storage

The extension may use Chrome's local storage to save extension settings such as whether download interception is enabled.

## Notifications

The extension may display local browser notifications to inform the user whether a download or magnet link was successfully sent to Burst or whether communication with the Burst application failed.

## Permissions

- `downloads`: Used to detect and intercept supported browser downloads.
- `nativeMessaging`: Used to communicate with the locally installed Burst desktop application.
- `contextMenus`: Used to provide the "Download with Burst" right-click option.
- `notifications`: Used to provide download status and error notifications.
- `storage`: Used to store extension settings locally.

## Third-Party Services

The Chrome extension does not use third-party advertising or analytics services.

The extension communicates with the Burst desktop application installed on the user's computer.

## Changes

This privacy policy may be updated when the extension's functionality or data handling changes.
